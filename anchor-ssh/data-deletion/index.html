Anchor SSH: Secure Terminal

Data deletion

This release does not create an Anchor cloud account or upload your SSH workspace to an Anchor service.

Remove local workspace data

You can remove saved session entries and connections from Connections and saved sessions in the app. Removing a connection removes its retained credentials; remove its saved session entries first. To remove all private local app data, use Android Settings → Apps → Anchor SSH → Storage → Clear storage, or uninstall the app. Android menu labels vary.

Clearing storage or uninstalling permanently deletes local profiles, retained credentials, saved commands, history and settings unless you have your own usable backup. Do not do this just to fix a connection problem.

Delete copies separately

Delete exported terminal logs, downloaded or shared backups and clipboard copies separately using the relevant app or file manager. Removing local data does not delete remote files, shell history or tmux processes. Manage those on your server.
