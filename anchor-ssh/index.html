Keep your session

With tmux installed on your server, reconnect to the same remote shell after a network interruption. Server shutdowns and terminated tmux sessions cannot be recovered.

A proper terminal

ANSI/VT emulation, scrollback, monospace type, terminal tabs, command shortcuts, and copy and paste controls.

Connect directly

Password or private-key authentication, host-key checks, Android Keystore protection, and screen capture protection enabled by default.

Install on Android

  1. Download the signed APK above on your Android device.
  2. Open the file. If Android asks, allow this browser or file manager to install this app. Turn that installation permission off again afterward.
  3. Open Anchor SSH and add your host, username, and authentication details. Verify the displayed host-key fingerprint against a trusted source before accepting it.
  4. Install tmux on your remote server before using persistent sessions. The app explains when it is missing; an ordinary SSH connection cannot guarantee process survival.

This download is signed with the developer's current review key. A future Google Play version may use a different app signing key and require uninstalling this review build. Export connection metadata first; credentials must be entered again.

Privacy & feedback

SSH connections go directly from the app to your chosen server. This review build has no public cloud backend configured. Connection credentials remain on your device unless you explicitly copy, export, or share information. Terminal logs may contain secrets; review them before sharing.
