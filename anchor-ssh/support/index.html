Support

Android local-workspace release. Purchases and cloud accounts are not enabled.

For help, email ofaruk1991@gmail.com. Include your app version from Settings → Help & build information, Android version, what you expected and what happened. Do not include passwords, private keys, server addresses you want to keep private, or sensitive terminal output.

Connect safely

Use a server you are authorized to access. Enter its address, SSH port and username, then choose password or private-key authentication. Verify the server's SHA-256 host-key fingerprint through a trusted channel before accepting it.

Keep remote work running

Install tmux on your remote server before using persistent sessions. The app reconnects to the saved tmux session after a dropped connection. A server reboot, removed session or exited process can end the workload. The app explains when tmux is unavailable; an unprotected shell requires your explicit consent.

A server key changed

Stop and verify the new fingerprint with your server administrator. A legitimate server reinstall can change a key, but an unexpected change can also indicate interception. Do not forget the old key merely to silence a warning.

Installing a test version

Join the specific Google Play test with the Google account approved for that track, then select the same account in the Play Store. An internal-test opt-in does not enroll you in a closed test. Google Play and separately downloaded APKs can use different signing keys; do not uninstall an app containing important local data without planning the migration.

Report a problem

Describe the steps that reproduce it and whether it occurs with a keyboard, touch input, a reconnect or an app restart. Redact screenshots and logs before sending them. Security reports should be sent privately to the support address above.

Privacy and deletion
